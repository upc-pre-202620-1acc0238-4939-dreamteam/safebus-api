# SafeBus API

API RESTful de SafeBus, una plataforma de seguridad para conductores y pasajeros del transporte público de Lima. Está desarrollada con Java 21, Spring Boot y MySQL, organizada en bounded contexts (IAM, Fleet, Trip, Passenger y Safety Case) con Domain-Driven Design. Documentación interactiva (Swagger): `/swagger-ui.html` del servicio desplegado en Railway.
